# High Liquidity Investments Analysation Tool

Этот проект представляет собой пример высоконагруженного бэкенд-сервиса на Go, предназначенный для сбора, кэширования и предоставления информации по вкладам, облигациям.

## Архитектура 

Сервис спроектирован с упором на надежность, предсказуемость и стабильность при высоких нагрузках:

- **Graceful Shutdown** 
- **HTTP таймауты**
- **Разделение слоев данных:**
  - **PostgreSQL** используется для надежного транзакционного хранения постоянных данных.
  - **Redis** используется как сверхбыстрый кэш для доступа к наиболее востребованным данным, значительно снижая нагрузку на основную БД.
- **Изолированный фоновый планировщик:**
- **Проверки состояния (Health Checks):** Встроены эндпоинты `/live` и `/ready` 
- **Безопасная обработка ошибок:**

## Кастомизация

Проект настраивается через переменные окружения в файле `.env` (см. `.env.example`):
- `PORT` — HTTP-порт (по умолчанию `8080`).
- `DATABASE_URL`, `REDIS_URL` — строки подключения к базе и кэшу.
- `BOND_BOARDS` — отслеживаемые доски облигаций (`RedisKey:Label`).
- `QUERY_COUNTS` — лимиты результатов поиска (например, `3,10`).
- `DEPOSITS_API_URL` — API-источник данных.

## Запуск и управление

Для удобного управления Docker-контейнерами в проекте есть готовые bash-скрипты:
- `./freshstart.sh` — полная сборка и запуск проекта.
- `./freshrestart.sh` — удаление всех контейнеров проекта.
- `./pause.sh` — приостановка работы контейнеров.
- `./continue.sh` — возобновление работы контейнеров.

## Доступные эндпоинты

- `GET /live` — Проверка жизнеспособности контейнера (liveness probe).
- `GET /ready` — Проверка готовности к приему трафика (readiness probe).
- `GET /metrics` — Метрики приложения.
- `GET /bonds?board={board}` — Получение информации об облигациях. Поддерживает фильтрацию по площадкам (`board`).
- `GET /query` — Поисковые запросы (с лимитами из `QUERY_COUNTS`).
- `GET /stats` — Статистика по финансовым инструментам.
